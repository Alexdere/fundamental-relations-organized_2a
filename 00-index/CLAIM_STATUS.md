# Claim status and document review conventions

This archive preserves evolving research, including attempts, revisions, and open questions. The index does not certify claims made in source files.

| Status | Meaning |
|---|---|
| Exact identity | Equality checkable by algebra or formal derivation |
| Conditional argument | Depends on one or more explicitly stated assumptions |
| Computational observation | Finite experiment, not an all-input proof |
| Conjecture | Open mathematical proposal |
| Physical interpretation | Model, analogy or speculative application |
| Superseded/retracted | Historical content superseded by later correction, with evidence |

For a later claim ledger, record: source file, statement, assumptions, status as claimed by source, independent verification status, dependencies, and later revisions. Do not silently promote exploratory hypotheses to theorems.

**Review priorities:** `the_24_theorem.md`, `collatz-proof-attempt.md`, `collatz-formalization.md`, foundational axioms, and cascade-to-Collatz bridge arguments.

All original files remain byte-for-byte intact. This directory-level organization is deliberately conservative.
