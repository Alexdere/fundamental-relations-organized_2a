# Interactive browser explorers

Standalone HTML files for cascade geometry, SFR prime circles, and Collatz modular/2-adic behavior.

## A sensible reading route

Try cascade_space.html and cascade_explorer (1).html for geometry, sfr_prime_circle*.html for prime-related displays, and collatz_mod8_2adic_explorer.html for arithmetic. Displays illustrate finite/model structures, not mathematical proof.

## Reader's caution

This is an exploratory research archive. Historical use of words like *proof*, *theorem*, *forced* or *verified* is not independent mathematical validation. Source files have not been rewritten or re-run.
