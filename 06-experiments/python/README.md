# Python research scripts

Collatz dynamics, continued fractions, Pell constraints, inverse maps, modular arithmetic, triangle tests and genesis visualization generation.

## A sensible reading route

The collatz_*.py programs address closely related parts of the cycle investigation; genesis_cascade.py produces cascade imagery; mod5_field.py and mod8_graph_v2.py probe modular structures. Not independently tested after migration.

## Reader's caution

This is an exploratory research archive. Historical use of words like *proof*, *theorem*, *forced* or *verified* is not independent mathematical validation. Source files have not been rewritten or re-run.
