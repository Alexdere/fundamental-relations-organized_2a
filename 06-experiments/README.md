# The experimental workshop

Research code, browser-based graphics and a shell runner separated from prose and claims.

## A sensible reading route

Go to python/ for numerical studies, interactive-html/ for explorations in a browser, and scripts/ for execution support. Existing source files are byte-identical to originals; hard-coded paths and dependencies may need repair.

## Reader's caution

This is an exploratory research archive. Historical use of words like *proof*, *theorem*, *forced* or *verified* is not independent mathematical validation. Source files have not been rewritten or re-run.
