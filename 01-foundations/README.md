# SFR and the founding vocabulary

Early frameworks, ontology, primitives, axiom proposals, and conceptual experiments. This directory preserves multiple evolving versions, not a single final axiomatization.

## A sensible reading route

Suggested reading: formal_framework.md (May 13), SFR_synthesis_document.md (May 16), fundamental_relations_framework_2026-05-19.md, then FR_machines.md as a toolbox. ontological_adventure.md is explicitly exploratory.

## Reader's caution

This is an exploratory research archive. Historical use of words like *proof*, *theorem*, *forced* or *verified* is not independent mathematical validation. Source files have not been rewritten or re-run.
