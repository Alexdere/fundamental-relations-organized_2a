# Unidentified sketches

Original numbered Untitled drawing files plus one Norwegian-titled drawing.

## A sensible reading route

These must be visually inspected and assigned meaningful catalog metadata. Untitled drawing (2).png and (3).png are identical. No file is renamed or discarded.

## Reader's caution

This is an exploratory research archive. Historical use of words like *proof*, *theorem*, *forced* or *verified* is not independent mathematical validation. Source files have not been rewritten or re-run.
