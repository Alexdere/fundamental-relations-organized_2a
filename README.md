## Preservation and caveats

- Original Git blob SHAs for all 85 files are unchanged. No exact duplicates have been deleted.
- Documents with names like “proof attempt”, “formal framework”, or “theorem” may include unproven proposals. Independent mathematical auditing remains to be done.
- Historical contradictions are preserved rather than silently corrected.
- Internal relative links and hardcoded paths in original documents/scripts may need to be adjusted in a separate follow-up pass.
- An imported ZIP is retained to make the provenance easy to inspect.
